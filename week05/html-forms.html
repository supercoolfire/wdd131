  2. Best Practices for Web Forms

    WebForms Part 2 Best Practices for Web Forms

    • Labeling
      • never use the word "submit" on a button, use a verb that answers I want to... e.g.: "Purcahse My Ticket"
      • Personalize the message with their name
      • Don't ask unnecessary questions that look like data mining, only ask for information that is necessary to complete the transaction.
    • Content
      • Remove unnecessary questions
      • Clearly identify required fields
    • Layout
      • Place labels above and left aligned
      • Never use multiple columns for a form
      • Use a single input for a phone number
      • Use radio buttons for less than 5 options. Use dropdowns for more than 5 options.
    • Inputs
      • Use a placeholder text to reduce the confusion
      • Order choices logically
      • Wrap all inputs in labels
    • Submission
      • never add a reset button to your page
      • Show a confirmation page
    • Design
      • Beautiful desgin inspires confidence
      • Minimum Input height of 44px
      • Group relatedf information
      • Chunk large forms using fildsets
